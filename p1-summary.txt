- Headless Chromium with software WebGL runs the sim at about 0.08x real time: browser tests must measure Flight.time (or set Render3D.skipDraw = true), never the wall clock.
- Gear.points(p, wheels, cz): optional third argument cz (the vessel's com.z) picks the side (sign(partZ - cz)); default 0. Contacts per track part = def.track.n; contact radius r + 0.4*travel (the stand-in Gear.ground is rigid, so a parked track sits 0.4*travel above the ground until 2A's suspension takes up the sag). The stand-in Gear.ground reuses vessel.js's rigid contact arithmetic, skid-steers each side toward its belt speed, lets old Car Wheels roll free, keeps contactTime/landed/restTime/splashed/wheelsDown/canDrive/wheelSpeed; it allocates per step and an 8x8 can exceed vmax while turning. 2A replaces all of it.
- cleanMm returns undefined when def.armour has no min/max (fixed armour: rings, tracks, wheels, skirts, slats): such parts never save mm.
- Applique Plate: armour.edge [1,1,1,1] plus armour.slab: massPerMm uses w x depth for a slab (one steel sheet).
- Aim.groupsOfParts builds a 'base' set (parts reached from the ring through non-members whose top is at or below the ring top + 0.05) and the att walk never passes the ring, so a turret-first design turns only its turret. An aimed part's own yaw and elevation pivot on its trunnion T = partPt(p, 0, -h/2 + pivot*h) (pinned by a test; parts3d's tankGun yaw node must sit at the trunnion with the pitch node at its origin).
- GroundAI.frame is called only when v.gv || v.kind === 'tank' || S.gai || GroundAI.battle. Flight.revert calls GroundMode.soloPlace only for kind tank. The 3-nearest-wrecks smoke cap is already in Combat.frame (gated on v.wreck). Flight.railsTick also skips kin/wreck vessels.
